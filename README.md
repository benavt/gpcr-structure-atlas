# Human β2AR structure atlas

Interactive atlas of 1,000 BioEmu2 conformers and two explicitly qualified engineered experimental state anchors: inactive 2RH1 chain A and active 3SN6 chain R. Both clusterings and all projections use 272 shared observed Cα positions. Mutation sites 96, 98 and 187 are excluded from every model; no experimental coordinates were imputed or repaired.

The site includes UMAP KNN and HDBSCAN views, PCA/UMAP/t-SNE, exact-model inspection, medoids, aligned ensembles, distance maps, TM grids, native Bonsai trees, memberships and coordinate downloads. Reference proximity does not establish biological state or antagonism.

This repository contains the reviewed static publication only. Scientific generation and clustering do not run during deployment.

Experimental sources: [2RH1](https://www.rcsb.org/structure/2RH1), [3SN6](https://www.rcsb.org/structure/3SN6). Target: [UniProt P07550](https://www.uniprot.org/uniprotkb/P07550/entry). Prediction method: [BioEmu2](https://github.com/microsoft/bioemu2).
